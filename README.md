# 📚 Estudo de `display` no CSS

Projeto desenvolvido para estudar a propriedade `display` do CSS e entender seus principais valores e casos de uso na construção de layouts.

## 🎯 Objetivo

Explorar, na prática, como diferentes valores de `display` alteram o comportamento e o posicionamento dos elementos HTML.

## 📌 Conceitos estudados

Neste projeto são abordados valores como:

- `block` — o elemento ocupa toda a largura disponível e inicia uma nova linha.
- `inline` — o elemento permanece na mesma linha e ocupa apenas o espaço necessário.
- `inline-block` — combina características de elementos `inline` e `block`.
- `flex` — facilita a criação de layouts unidimensionais, organizando elementos em linhas ou colunas.
- `grid` — permite criar layouts bidimensionais, trabalhando com linhas e colunas.
- `none` — remove o elemento do fluxo da página.
